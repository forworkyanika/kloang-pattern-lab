# Kloang Pattern Lab

เว็บทดลองลายกลบทไทยด้วย **first-occurrence encoding ระดับทั้งบท** (Method 4+) — พอร์ตจาก `method4_poem_level.py`

**ใช้งาน:** https://forworkyanika.github.io/kloang-pattern-lab/

## ทำอะไรได้

- ใส่กลอนเองได้หลายบท (เก็บในเบราว์เซอร์, ส่งออก/นำเข้า JSON)
- เลือก **ต้นแบบ** เพื่อดึง "กฎของกลบท" — เลือกหลายบทจะได้เฉพาะกฎที่ทุกบทมีร่วมกัน (intersection)
- เลือก **ทดสอบ** หลายบท แล้วดูคะแนนผ่านกฎ, ลายตัวอักษร, และกฎที่ไม่ผ่านพร้อมตำแหน่ง
- เปิด/ปิดกฎทีละข้อ เพื่อทดลองว่ากฎไหนสำคัญ
- ดู back-reference (NEW / SAME / CROSS) และ equality matrix ของแต่ละบท
- ส่งออกผลเป็น CSV

## รูปแบบการพิมพ์กลอน

```
ผล บุญ บุญ เกื้อ กอบ | ยศ ศักดิ์
ผล บาป บาป คง ชัก | ชั่ว ให้
ผล สัตย์ สัตย์ ประ จักษ์ | คุณ แน่ | นา พ่อ
ผล เท็จ เท็จ โทษ ได้ | เที่ยง แท้ แก่ ตน
```

1 บรรทัด = 1 บาท · เว้นวรรคระหว่างพยางค์ · `|` คั่นวรรค (วรรคที่ 3 = คำสร้อย)
พิกัด `บ3.ว0.2` = บาท 3, วรรคหน้า (0), ตำแหน่งที่ 2 (เริ่มนับ 0)

| ไฟล์ | หน้าที่ |

| `kloang.js` | ตรรกะทั้งหมด (parse, first-occurrence, letter pattern, back-reference, rules, intersection, check) |

| `tests/kloang.test.js` | ทดสอบว่าผลตรงกับเวอร์ชัน Python — รัน `node tests/kloang.test.js` |

## หมายเหตุ
